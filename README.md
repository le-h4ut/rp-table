# RP Table

Первая версия личного игрового стола для своей НРИ. Тёмная тема, маджента, управление с телефона и компьютера.

## Что уже можно

- Задать название и размер поля от 1×1 до 50×50 клеток. Клетка — 2 метра.
- Создать до 200 персонажей с именем и полосками HP/OH, редактировать значения.
- Создать свою структуру папок: вложить, переименовать или перенести папку. Карточки можно распределять по папкам. Пока тип карточки один — «Персонаж».
- Поставить персонажа на поле, перетащить мышью или пальцем, переместить кнопкой из карточки, убрать в резерв. Обе полоски находятся под кружком токена.
- Работать без аккаунта с сохранением в этом браузере. После входа можно перенести гостевое поле в пустой аккаунт.
- Войти через Google или почту с паролем и сохранять поле в Firebase. В аккаунте можно привязать второй способ входа.

Библиотека открывается левой кнопкой в шапке, нижней панели нет. Выберите папку перед созданием карточки или вложенной папки. Чтобы изменить папку карточки, откройте её и выберите другое место в поле «Папка».

На телефоне поле прокручивается по пустым клеткам. Токен можно переносить пальцем; перенос на занятую клетку отменяется. Другой способ: нажмите токен → «Переместить на поле» → клетка. Для персонажа в резерве доступна кнопка «Поставить на поле».

В «Текущее» можно ввести `1000` для замены, `+1000` для прибавления, `-1000` для вычитания. Enter пересчитывает значение и полоску прямо в карточке. Повторное вычисление идёт от результата предыдущего. Только «Сохранить» применяет правки к персонажу; «Отмена» их отбрасывает.

Превышение обрезается автоматически: HP — до MAX HP, OH — до разрешённых 150% MAX OH. Отрицательные итоги и некорректный ввод показывают ошибку.

HP не превышает максимума. OH допускает 150% максимума и меняет цвет при превышении. Числа — целые, максимум характеристики 1 триллион. Броски, оружие, эффекты, общий стол нескольких игроков и автоматический бой пока не реализованы.

## Сохранения

Без входа — localStorage, привязанный к браузеру. При входе — отдельный локальный черновик для каждого UID и один облачный документ `/users/{uid}/boards/main`. Очистка данных браузера удаляет локальные сохранения.

Облако хранит ограниченный JSON-снимок поля (до 160000 символов), ревизию, ID изменения и серверное время. Клиент проверяет содержимое снимка. Правила ограничивают доступ владельцем, путь, размер, типы оболочки и последовательность ревизий. Семантику JSON сервер не проверяет; владелец может испортить собственный снимок сторонним клиентом, но не получает доступ к чужому.

Сначала загружается серверная версия. Если два устройства правили разные версии, программа сохраняет локальный черновик и предлагает скачать его либо загрузить облачную версию. Автоматического объединения конфликтов нет. Скачанный JSON пока служит резервной копией: импорта файлов в v0 нет.

## Запуск

Нужен Node.js 24+.

```sh
npm ci
npm run dev
npm test
npm run build
```

Браузерная проверка: запустите dev-сервер, затем `npm run test:browser`. Нужен Edge в Windows либо установленный Chromium Playwright в Linux. Можно указать `BROWSER_PATH`. Тест проверяет папки, карточку, ввод с Enter, обе полоски, перенос мышью/касанием и разные размеры экрана. Live-проверка Firebase запускается отдельно: `$env:LIVE_QA='1'; node tests/cloud-smoke.mjs` в PowerShell. Она создаёт одноразовый аккаунт и удаляет его вместе с документом в конце.

В Windows при ограничении PowerShell используйте `npm.cmd`.

Firebase: проект `rp-table-6644d`, Standard Firestore, Authentication Google + Email/Password. Конфигурация веб-клиента в `src/firebase.ts` публичная; административных ключей в репозитории нет. Доступ защищается `firestore.rules`, а не секретностью API key. Analytics не подключена.

При смене адреса сайта добавьте его домен в Firebase Authentication → Settings → Authorized domains. Для текущего размещения разрешён `le-h4ut.github.io`.

Правила Firestore проверяются и публикуются отдельно от сайта:

```sh
npx firebase-tools deploy --only firestore:rules --dry-run --project rp-table-6644d
npx firebase-tools deploy --only firestore:rules --project rp-table-6644d
```

GitHub Actions проверяет тесты, собирает сайт и публикует `dist` на GitHub Pages после push в `main`. В настройках Pages должен быть выбран GitHub Actions. Тарифы и квоты Firebase остаются ограничениями сервиса; приложение не предполагает безлимитного хранения.
